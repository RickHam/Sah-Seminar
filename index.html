Uvod i motivacija

Šah pripada klasi antagonističkih igara koje se temelje na ideji da pobjeda jednog igrača znači direktan poraz drugog igrača. Također je deterministička igra s potpunom informacijom. Slučajnost ne igra nikakvu ulogu.

Stablo igre

Determinističku igru dvaju igrača s potpunom informacijom modeliramo usmjerenim stablom \(T = (V, E)\):

  • Korijen \(v_0 \in V\): Početno stanje igre
  • Skup čvorova \(V\): Pozicije. Svakom neterminalnom čvoru pridružen je igrač na potezu \(P(v) \in \{\text{MAX}, \text{MIN}\}\). Šahovsku poziciju jednoznačno definiramo položajem figura, vrijednosti P(v), mogučnost rošada, ,mogučnost en passanta i brojem poteza od zadnje pojedene figure ili pomaknutog pješaka.
  • Usmjereni bridovi \(E\): Legalni potezi koji vode iz jednog stanja u drugo.
  • Listovi (terminalni čvorovi) \(V_T \subset V\): Završne pozicije partije (mat, pat, remi) gdje je definirana funkcija isplate \(f \colon V_T \to \{-1, 0, 1\}\) prema Shannonovoj definiciji. Nekad se uzima da je kodomena = {0, 1/2, 1}

Svaki usmjereni put od korijena \(v_0\) do nekog lista u \(V_T\) predstavlja jednu odigranu partiju. Prema Trompu (2022.), ukupan broj mogućih legalnih šahovskih pozicija iznosi približno \(4.822 \times 10^{44}\)[izvor: 3]. Ako uzmemo u obzir da prosječno postoje 30 legalnih poteza \(b \approx 30\) i prosječno trajanje partije od \(d \approx 80\) polupoteza, veličina stabla iznosi \(b^d = 30^{80} \approx 10^{120}\) (Shannonov broj). Trebamo funkciju evaluacije.

Evaluacija pozicije i njezina ograničenja

Uvodimo funkciju statičke evaluacije \[Eval: V \to \mathbb{R}\] Ideja je da u zadanoj dubini statički odredimo realnu vrijednost pozicije. Pozitivna predstavlja prednost bijelog, negativna prednost crnog. Shannon je predložio svoju funkciju:

\[ Eval(P) = 200(K - K') + 9(Q - Q') + 5(R - R') + 3(B - B' + N - N') + (P - P') - 0.5(D - D' + S - S' + I - I') + 0.1(M - M') \]

gdje su uzeti u obzir materijal, poduplani (\(D\)), izolirani (\(I\)) i zaostali (\(S\)) pješaci te mobilnost figura (\(M\)). Do prošlog desetljeća se razvoj temeljio na ručno kodiranje parametara. (primjerice, IBM-ov Deep Blue koji je pobjedio Kasparova je 1997. koristio hardverski implementiranih 8000 ručno ugođenih parametara).

Minimax i alfa-beta podrezivanje

Kako stablo igre zbog njegove veličine ne možemo pretražiti u cjelini, pretragu ograničavamo na unaprijed zadanu dubinu \(d\). Minimax algoritam polazi od pretpostavke da oba igrača vuku najbolje moguće poteze: igrač s bijelim figurama (MAX) nastoji postići što veću ocjenu pozicije, dok igrač s crnim figurama (MIN) tu istu vrijednost nastoji što više umanjiti. Rekurzivni izraz za Minimax vrijednost \(M(v)\) glasi:

\[ M(v) = \begin{cases} Eval(v), & \text{ako je } v \text{ list na dubini } d = 0 \\ \max_{w \in \text{djeca}(v)} M(w), & \text{ako je na potezu MAX (bijeli)} \\ \min_{w \in \text{djeca}(v)} M(w), & \text{ako je na potezu MIN (crni)} \end{cases} \]

Izvorni Minimax mora obići sve čvorove do zadane dubine, što je računski izuzetno zahtjevno. Znatno ubrzanje postižemo postupkom α-β podrezivanja, pri čemu tijekom obilaska stabla održavamo međe pretrage:

  • \(\alpha\): donja međa, odnosno najbolji (najveći) ishod koji je igrač MAX već osigurao duž trenutnoga puta (početno postavljen na \(-\infty\)).
  • \(\beta\): gornja međa, odnosno najnepovoljniji (najmanji) ishod na koji igrač MIN može prisiliti bijeloga (početno postavljen na \(+\infty\)).

Čim u promatranome čvoru se zadovolji uvjet \(\beta \le \alpha\), daljnji pregled te podgrane možemo prekinuti jer protivnik raspolaže potezom kojim sprječava prelazak u ta stanja. Dokaz ispravnosti je dan u prezentaciji.

Programski dio

U sklopu rada razvijena je demonstracijska Python implementacija Minimax algoritma i α-β podrezivanja nad općom strukturom stabla pozicija. Implementacija demonstrira mehanizam prosljeđivanja granica, ažuriranje parametara te prekidanje grana kada nastupi uvjet reza \(\beta \le \alpha\): 

import networkx as nx
import matplotlib.pyplot as plt
import random
import copy
import time
from typing import Optional

BIJELA = 1
CRNA = 0

class Stablo:
    def __init__(self, boja: bool, evaluacija: Optional[float] = None):
        self.boja = boja
        self.evaluacija = evaluacija
        self.djeca: list['Stablo'] = []

    def dodaj_dijete(self, dijete: 'Stablo'):
        self.djeca.append(dijete)

    def daj_boju(self):
        return self.boja
    
    def daj_evaluaciju(self):
        return self.evaluacija

    def postavi_evaluaciju(self, eval):
        self.evaluacija = eval

    def je_list(self):
        return len(self.djeca) == 0


def staticka_evaluacija(pozicija: Stablo):
    # U svrhu primjera koristimo uniformnu raspodjelu
    return random.uniform(-10, 10)


def minimax(pozicija: Stablo, dubina: int, bojaIgraca: bool):
    najbolje_dijete = None
    if dubina == 0 or pozicija.je_list():
        if pozicija.evaluacija is None:
            pozicija.evaluacija = staticka_evaluacija(pozicija)
        return pozicija.evaluacija, None

    if bojaIgraca == BIJELA:
        najbolja_evaluacija = float('-inf')
        for dijete in pozicija.djeca:
            vrijednost, _ = minimax(dijete, dubina - 1, CRNA)
            if vrijednost > najbolja_evaluacija:
                najbolja_evaluacija = vrijednost
                najbolje_dijete = dijete
        
    if bojaIgraca == CRNA:
        najbolja_evaluacija = float('inf')
        for dijete in pozicija.djeca:
            vrijednost, _ = minimax(dijete, dubina - 1, BIJELA)
            if vrijednost < najbolja_evaluacija:
                najbolja_evaluacija = vrijednost
                najbolje_dijete = dijete

    pozicija.evaluacija = najbolja_evaluacija   
    return najbolja_evaluacija, najbolje_dijete


def alfa_beta_podrezivanje(pozicija: Stablo, dubina: int, bojaIgraca: bool, 
                           alpha: float = float('-inf'), 
                           beta: float = float('inf')):
    najbolje_dijete = None
    if dubina == 0 or pozicija.je_list():
        if pozicija.evaluacija is None:
            pozicija.evaluacija = staticka_evaluacija(pozicija)
        return pozicija.evaluacija, None

    if bojaIgraca == BIJELA:
        najbolja_evaluacija = float('-inf')
        for dijete in pozicija.djeca:
            vrijednost, _ = alfa_beta_podrezivanje(dijete, dubina - 1, CRNA, alpha, beta)
            if vrijednost > najbolja_evaluacija:
                najbolja_evaluacija = vrijednost
                najbolje_dijete = dijete
            alpha = max(najbolja_evaluacija, alpha)
            if beta <= alpha:
                break

    if bojaIgraca == CRNA:
        najbolja_evaluacija = float('inf')
        for dijete in pozicija.djeca:
            vrijednost, _ = alfa_beta_podrezivanje(dijete, dubina - 1, BIJELA, alpha, beta)
            if vrijednost < najbolja_evaluacija:
                najbolja_evaluacija = vrijednost
                najbolje_dijete = dijete
            beta = min(najbolja_evaluacija, beta)
            if beta <= alpha:
                break

    pozicija.evaluacija = najbolja_evaluacija   
    return najbolja_evaluacija, najbolje_dijete

Stockfish i NNUE

Stockfish je godinama bio vodeći predstavnik klasične α-β pretrage s ručno pisanim evaluacijama (HCE). Prekretnica u njegovom razvoju dogodila se uvođenjem NNUE (Efficiently Updatable Neural Network — učinkovito ažurabilna neuronska mreža) arhitekture, koju je 2018. razvio Yu Nasu za Shogi, a u kolovozu 2020. službeno je integrirana u Stockfish 12.

NNUE zamjenjuje klasičnu Shannonovu evaluaciju plitkom neuronskom mrežom koja se izvodi izravno na procesoru (CPU). Ključne prednosti ove arhitekture su:

  • Inkrementalno (diferencijalno) ažuriranje: Budući da jedan potez mijenja položaj tek jedne ili dviju figura, akumulator prvog sloja mreže ne računa se ispočetka matricama, već se primjenjuje brza vektorska diferencija — težine odlaznog polja se oduzimaju, a težine dolaznog polja dodaju.
  • CPU optimizacija i SIMD instrukcije: Korištenjem cjelobrojne aritmetike (int8 i int16) te modernih AVX2/AVX-512 vektorskih instrukcija procesora, mreža postiže brzine od preko 50 milijuna evaluacija u sekundi. Za više informacija pogledati izvor 7.

Time je Stockfish zadržao ogromnu dubinu pretrage koju omogućuje α-β podrezivanje, ali uz pozicijsku točnost evaluacije svojstvenu neuronskim mrežama.

AlphaZero i MCTS

U prosincu 2017. DeepMind predstavlja AlphaZero, sustav koji je u potpunosti napustio Minimax stablo i klasične evaluacijske heuristike, svladavši tadašnji Stockfish 8 isključivo samostalnim učenjem (reinforcement learning kroz self-play).

AlphaZero koristi Monte Carlovu Pretragu Stabla (MCTS), algoritam koji stablo igre gradi asimetrično. Umjesto pretrage svih poteza do fiksne dubine, simulacije se usmjeravaju duž najperspektivnijih grana kroz četiri faze:

  1. Selekcija (Selection): Krećući se od korijena prema dolje, biraju se potezi koji balansiraju kvalitetu i istraživanje pomoću PUCT formule vođene apriornom vjerojatnošću mreže.
  2. Ekspanzija (Expansion): Dolaskom do stanja koje još nije u stablu, stvara se novi čvor.
  3. Evaluacija (Evaluation): Duboka rezidualna konvolucijska mreža \(f_\theta(s) = (\mathbf{p}, v)\) procjenjuje poziciju: vektor \(\mathbf{p}\) daje vjerojatnosti poteza, a skalar \(v \in [-1, 1]\) procjenu vjerojatnosti pobjede.
  4. Propagacija unatrag (Backpropagation): Dobivena procjena propagira se natrag do korijena, ažurirajući broj posjeta i akumuliranu vrijednost čvorova.

Zbog iznimne preciznosti duboke mreže, AlphaZero je pretraživao tek oko 60.000 pozicija u sekundi (u usporedbi s desecima milijuna kod Stockfisha), pokazavši nadmoć asimetrične pretrage vođene dubokim reprezentacijama nad sirovom dubinom grananja. Više informacija u izvorima 4, 5
